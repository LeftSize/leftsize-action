# Security policy

## Reporting a security issue

Please don't open a public GitHub issue for a security problem. Email **hi@leftsize.com** with "Security" in the subject instead, and include:

- what you found and where (a URL, an API endpoint, or a file and line in this repository)
- the steps to reproduce it, and what an attacker could do with it
- how we can reach you

We confirm that we received your report within a few working days and keep you informed while we work on a fix. Please don't share the issue publicly until it's fixed, and don't access or change data that isn't yours while testing. LeftSize has no bug bounty program.
